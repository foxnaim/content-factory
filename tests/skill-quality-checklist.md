# Общий checklist качества skills

- [ ] YAML frontmatter содержит точные `name` и `description`.
- [ ] Description объясняет, когда skill применять, и не перехватывает чужие задачи.
- [ ] Instructions написаны по-русски; English output создаётся только для англоязычного контента.
- [ ] Неизвестные факты, личные данные, скрины и источники сохраняются как утверждённые маркеры.
- [ ] Есть разделы ограничений и контроля качества.
- [ ] Есть два хороших и два плохих примера с наблюдаемой разницей.
- [ ] References и templates доступны из `SKILL.md`.
- [ ] Скрипты детерминированы, не читают секреты и имеют smoke test.
- [ ] Нет автопубликации, обхода правил, накрутки, чужих материалов без лицензии и обещаний результата.
- [ ] Выход заканчивается ручным review.

Автоматическая часть: `npm run skills:test`.
