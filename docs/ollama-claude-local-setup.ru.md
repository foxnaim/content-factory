# Claude + Ollama + Qwen локально: проверяемая установка

Этот гайд подключает Claude Code или Claude Desktop к локальной модели Ollama. Он не устанавливает «модель Claude»: интерфейс Claude используется как клиент, а ответы генерирует выбранная локальная модель `qwen2.5-coder:14b`.

`qwen2.5-coder:14b` занимает около 9 ГБ и имеет окно контекста 32K. Этого достаточно для небольших задач и отдельных модулей, но для длинной автономной работы над большим репозиторием контекст ограничен. Не обещайте зрителю скорость или качество до теста на его компьютере.

Проверено 23 сентября 2026 года на машине автора: Ollama `0.34.3` видит `qwen2.5-coder:14b` как локальную модель размером 9,0 ГБ, а прямой тест `ollama run` завершился ответом `LOCAL_OK`. Подключение через интерфейс Claude проверяется отдельно после завершения загрузки клиента.

## Вариант A: через приложение Ollama

1. Установите и запустите актуальную версию Ollama.
2. В Ollama откройте интеграцию **Claude** и включите её.
3. Дождитесь завершения окна **Downloading Claude**. Не закрывайте Ollama во время загрузки.
4. В настройках Claude-интеграции выберите локальную модель `qwen2.5-coder:14b`.
5. Откройте новый чат и выполните короткую проверку из раздела ниже.
6. Чтобы вернуть обычное подключение Claude, выключите интеграцию Claude в Ollama.

## Вариант B: через терминал

Проверьте Ollama:

```bash
ollama --version
```

Загрузите модель:

```bash
ollama pull qwen2.5-coder:14b
```

Убедитесь, что она установлена:

```bash
ollama list
```

Запустите Claude Code через Ollama:

```bash
ollama launch claude --model qwen2.5-coder:14b
```

Если команда `ollama launch` недоступна, обновите Ollama. Для ручного подключения Claude Code можно использовать совместимый Anthropic endpoint:

```bash
export ANTHROPIC_AUTH_TOKEN=ollama
export ANTHROPIC_BASE_URL=http://localhost:11434
claude --model qwen2.5-coder:14b
```

Не сохраняйте реальные API-ключи в репозитории. Для локального endpoint значение `ollama` является служебной строкой, а не секретом.

## Проверка после установки

Сначала попросите модель только прочитать состояние проекта:

```text
Работай только в текущем репозитории. Сначала ничего не изменяй.

1. Покажи абсолютный путь текущего каталога и название Git-ветки.
2. Найди README.md, AGENTS.md, package.json и docker-compose.yml.
3. Прочитай инструкции проекта и кратко опиши архитектуру.
4. Выполни только безопасные проверки: версии Node, Docker и Ollama, затем предложи команды тестов.
5. Не удаляй файлы, не раскрывай секреты, не публикуй контент и не отправляй данные наружу.

В конце выведи таблицу: «проверка / результат / что исправить».
```

Затем дайте Claude проверочный запрос с разрешением на тесты:

```text
Проведи локальный smoke-test проекта по README и AGENTS.md.

- не удаляй существующие файлы;
- не меняй .env и не показывай его содержимое;
- не включай автоматическую публикацию;
- сначала проверь Docker Compose config, типы и тесты;
- после этого запусти только необходимые локальные сервисы;
- создай один тестовый draft, но остановись на ready_for_review;
- зафиксируй точные команды, ошибки и проверенные результаты;
- если проверка не выполнена, так и напиши — не выдавай предположение за факт.
```

Успешная установка подтверждена, когда модель отвечает через Claude-интерфейс, видит только разрешённый каталог, может прочитать файлы и не просит Anthropic API key. Это ещё не подтверждает качество модели на больших задачах — его оценивают отдельным тестом на реальном репозитории.

## Кадры для Reels/Shorts

Снимайте вертикально или оставляйте безопасную центральную область для кропа 9:16. Не показывайте токены, `.env`, личные пути, уведомления и другие окна.

1. **Хук, 0–2 сек.** Ollama и текст: «Claude может работать с локальной моделью?»
2. **Установка, 2–5 сек.** Реальный экран `Downloading Claude` с индикатором прогресса.
3. **Модель, 5–9 сек.** Терминал с `ollama pull qwen2.5-coder:14b`; скройте имя пользователя в prompt.
4. **Проверка, 9–12 сек.** `ollama list`, где видна точная модель.
5. **Запуск, 12–16 сек.** `ollama launch claude --model qwen2.5-coder:14b`.
6. **Тест, 16–23 сек.** Claude читает README и возвращает короткую таблицу проверок.
7. **Честное ограничение, 23–27 сек.** Карточка: «14B · около 9 ГБ · контекст 32K».
8. **Результат, 27–32 сек.** Экран Content Factory со статусом `ready_for_review`.
9. **CTA, 32–35 сек.** «Гайд и исходники — в Telegram/GitHub после полного теста».

Обязательные реальные скриншоты:

- `[ДОБАВИТЬ РЕАЛЬНЫЙ СКРИН]` Ollama → Claude до включения;
- `[ДОБАВИТЬ РЕАЛЬНЫЙ СКРИН]` окно Downloading Claude;
- `[ДОБАВИТЬ РЕАЛЬНЫЙ СКРИН]` завершённый `ollama pull`;
- `[ДОБАВИТЬ РЕАЛЬНЫЙ СКРИН]` результат `ollama list`;
- `[ДОБАВИТЬ РЕАЛЬНЫЙ СКРИН]` успешный запуск Claude с названием модели;
- `[ДОБАВИТЬ РЕАЛЬНЫЙ СКРИН]` фактический результат smoke-test.
