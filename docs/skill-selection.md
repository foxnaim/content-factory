# Как выбирать skill

| Задача | Skill | Следующий шаг |
|---|---|---|
| Выбрать направление канала и первые темы | `youtube-niche-research` | ручной выбор тем → batch planner |
| Написать Shorts по одной теме | `shorts-scriptwriter` | retention audit → storyboard |
| Усилить уже готовый сценарий | `shorts-retention-audit` | утвердить исправленную версию |
| Подготовить title и thumbnail | `youtube-title-thumbnail` | ручной выбор упаковки |
| Спланировать faceless-визуалы | `faceless-video-storyboard` | проверить лицензии → assets generation |
| Проверить авторский вклад и reused-content риск | `youtube-originality-qa` | revise/block/human review |
| Импортировать 10–1000 тем | `content-factory-batch-planner` | CSV/JSON import → явная queue action |
| Перенести материал в Telegram | `telegram-repurpose` | перечитать пост и создать нативный poll |

Обычная цепочка: `niche research → batch planner → scriptwriter → retention audit → title/thumbnail + storyboard → originality QA → Content Factory render → human review → ручная публикация`. Для одного ролика исследование ниши и batch planner можно пропустить.

Не запускай все skills автоматически. Загружай только тот модуль, который нужен текущему решению, и его конкретную reference. Это сохраняет контекст и не смешивает редакционные роли.
