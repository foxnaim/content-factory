# Планировщик batch для Content Factory

Получи список 10–1000 тем, канал, язык, форматы, шаблоны, дневной лимит и бюджет/лимиты, если они заданы. Если лимит не задан, не выдумывай его: используй `[ДОБАВИТЬ МОИ ДАННЫЕ]` и не составляй календарь публикации.

## Рабочий процесс

1. Нормализуй пробелы, регистр для сравнения и стабильный `external_id`, сохранив исходный текст темы.
2. Найди точные и смысловые дубли. Не удаляй молча: пометь группу и предложи объединение/разные доказательства.
3. Сгруппируй темы в серии по аудитории, проблеме и формату. Не делай 1000 вариаций одного шаблона.
4. Назначь приоритет `high`, `normal` или `low` с объяснимыми причинами, без прогноза просмотров.
5. Сформируй нормализованный CSV для API и JSON manifest с ручной QA-выборкой.
6. Используй только статусы: `idea`, `research`, `script_draft`, `review`, `approved`, `rendered`, `qa_pending`, `ready_to_publish`, `published`, `rejected` в редакционном плане. При импорте в текущий API сопоставь их с lifecycle проекта по [references/status-mapping.md](references/status-mapping.md).
7. Никакой автоматической публикации: `ready_to_publish` остаётся ручным решением вне batch-worker.

Для детерминированной нормализации доступен [scripts/normalize-batch.mjs](scripts/normalize-batch.mjs). Форматы: [references/batch-contract.md](references/batch-contract.md).

## Ограничения и что нельзя утверждать

- Не обещай производительность, просмотры, доход или экономию без измеренных данных.
- Не создавай однотипный mass-produced batch ради количества.
- Не добавляй автопостинг, накрутку и обход лимитов платформ.
- Не записывай API-ключи в CSV/JSON, логи или примеры.

## Контроль качества перед выдачей результата

- В batch от 10 до 1000 валидных строк, стабильные ID и нет скрытых точных дублей.
- Смысловые дубли помечены для человека; QA-выборка включает каждую серию и высокий риск.
- CSV парсится, JSON валиден, язык/длительность/формат не потеряны.
- Выход не содержит команд публикации и требует ручного review.
- Запусти [tests/smoke-test.mjs](tests/smoke-test.mjs) и общий валидатор skills.
