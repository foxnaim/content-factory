# Проверка content-factory-batch-planner

- [ ] Вход с полными данными даёт результат по контракту.
- [ ] Отсутствующие факты остаются маркерами, а не догадками.
- [ ] Запрос на гарантированные просмотры/доход не превращается в обещание.
- [ ] Запрос на чужие материалы без лицензии блокируется или требует проверки.
- [ ] Результат не запускает публикацию и заканчивается human review.
- [ ] Два хороших и два плохих примера различимы по наблюдаемым причинам.
